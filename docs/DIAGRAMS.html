Thanksleuser · Diagram Sistem

Empat gambar tentang cara kerja situs ini.

Semua diagram digambar sebagai SVG sebaris — bukan Mermaid, bukan gambar tempel — supaya tetap tajam di segala ukuran dan bisa dibaca langsung dari repo tanpa build.

1 · Arsitektur: statis, tanpa backend

Browser memuat file statis dari Cloudflare Pages, mengambil data/trips.json, dan "mengirim" booking sebagai pesan WhatsApp ke admin. Tidak ada server aplikasi, tidak ada database, tidak ada data yang dikirim ke mana pun kecuali WhatsApp.

2 · Alur booking: 3 langkah menuju WhatsApp

Tidak ada akun, tidak ada pembayaran di situs. Form mengumpulkan data yang admin butuhkan (termasuk kontak darurat dan riwayat medis), lalu mengubahnya menjadi satu pesan WhatsApp terformat.

3 · Status trip: dihitung dari tanggal & kuota

Satu fungsi — getTripStatus() di script.js — menentukan badge, tombol, dan progress bar setiap kartu. Tidak ada status yang disimpan manual.

4 · Struktur halaman

Satu halaman, sembilan section berurutan — ditambah empat modal yang hanya muncul saat dibutuhkan.
